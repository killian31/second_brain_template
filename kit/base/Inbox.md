## For the agent
For each bullet, decide whether it is worth keeping. If it is, create or update the right note, link it, and remove the bullet from here. If it is not, remove it. Never invent facts. If a bullet is ambiguous, leave it and flag it. Keep the `## To process` heading and one empty bullet so the note is ready for the next capture.
